# MASS WIRE AND STEELS PVT. LTD., BHIWADI

## TUS MODULE: TEMPERATURE UNIFORMITY SURVEYS — MASTER LIST

**Basis:** AIAG CQI-9 4th Edition, HTSA question 3.4 ("Are temperature uniformity surveys performed per requirements in Process Tables?"): surveys conducted per the applicable Process Tables, Section 2.0; actions that alter the temperature uniformity characteristics of a furnace documented per P3.4.1.2; alternate test methods, if used, meeting P3.4.8; the upper temperature tolerance never exceeded (exceptions for multi-temperature process cycles per P3.4.5.1); the internal process specification defining the soak time at temperature for the pass / fail determination (P3.4.5.1); survey reporting per P3.4.7. Section numbers and figures to confirm against the controlled copy. PDCA: **Plan / Do / Check / Act** (pyrometry).

**Application:** CALOR Quality System (`QMS/00_Integrated_Application/calor-quality-system.html`) → Uniformity (TUS). The qualified ranges, the surveys with their readings and reports, the uniformity-affecting changes, the reactions to failed surveys and the HTSA 3.4 self-assessment are held there.

### Where each requirement is met

| Requirement (HTSA 3.4) | Met by | Evidence in the application |
|---|---|---|
| Surveys per the Process Tables, Section 2.0 | QP-TUS-01 §6.1–6.2; F-TUS-01 | Qualified ranges per chamber (tolerance, interval, Process Table reference); both ends surveyed and in date |
| Actions altering uniformity documented (P3.4.1.2) | QP-TUS-01 §6.6; F-TUS-03 | Change records with the decision and the re-survey; Process validation equipment changes not yet documented are flagged |
| Alternate test methods meet P3.4.8 | QP-TUS-01 §6.3 | A survey by an alternate method needs the method reference, justification and approval |
| Upper tolerance never exceeded (P3.4.5.1) | QP-TUS-01 §6.4; WI-TUS-02 | Every reading, also before stabilisation, is checked against set value + tolerance; an exception needs the multi-temperature cycle and its reason |
| Soak time defined by the internal process specification (P3.4.5.1) | QP-TUS-01 §6.4 | Soak time and its specification reference in Settings; each survey must cover the soak time after stabilisation |
| Reporting per P3.4.7 | WI-TUS-02; F-TUS-02 | Report gate: identification, set value and range, method, instrument and thermocouples with calibration and corrections, locations, readings with times, results, approval |

### First-cycle implementation checklist

- [ ] Approve QP-TUS-01, the WIs and the formats; set the soak time and its process specification reference in the application (Settings).
- [ ] Enter the qualified ranges of every chamber from Process Table A / E Section 2.0 and the furnace class (F-TUS-01).
- [ ] Record the latest survey of each range end with its readings and approve the reports (F-TUS-02).
- [ ] Record every change since the last survey that can alter uniformity and decide the re-survey (F-TUS-03).
- [ ] Close every failed survey with a passing re-survey; check that HTSA 3.4 reads Satisfactory; file the evidence.
