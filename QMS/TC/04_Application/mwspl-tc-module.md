# MASS WIRE AND STEELS PVT. LTD., BHIWADI

## TC MODULE: APPLICATION DESCRIPTION

The module runs in the CALOR Quality System (`QMS/00_Integrated_Application/calor-quality-system.html`, "Thermocouples"). Source: `QMS/TC/04_Application/mwspl-tc-module.js`; build `python QMS/00_Integrated_Application/build.py`. The documents of this module must match the rules below, which are taken from the code.

| Item | Value in the code |
|---|---|
| Records | collections `tcs` (elements `TE-nnnn`), `eq` (test TCs / instruments `TT-nnnn`), `sats` (`SAT-nnnn`), `tubes` (checks `PT-nnnn`), `config/settings`, `config/pm`; shared record store (prefix `tc-`) or this browser (`mws-tc-local-v1`) |
| Element | furnace, chamber, tag (TC-01 …; zone from the number, odd = right wall), use (control / monitoring / recording / load / over-temperature), type, serial, installed, calibration (certificate, date, range, largest error), range of use, protection tube (material, installed, check / replacement interval), status in use / spare / removed |
| Calibration (P3.1) `calIssues` | certificate, date on or before installation, range covering the range of use (defaults hardening 700–960, tempering 500–900 °C), largest error within ± the greater of 2.2 °C or 0.75 % (base metal) / 1.5 °C or 0.25 % (noble) at the top of the range; test TCs 1.1 °C or 0.4 % / 0.6 °C or 0.1 % — settings to confirm |
| SAT (P3.3) `satState` | control, monitoring, recording TCs: a valid passing SAT after installation, then every 90 days (setting); difference = furnace − (test + instrument correction + test TC correction); fail beyond ±5.5 °C (setting), warning beyond 70 %; a failure stays until a later pass |
| Test equipment `eq` (`TT-nnnn`) | ident, kind, type, correction for SATs, largest error, uses before the register; **calibration record**: make, model, serial, range from / to, least count, laboratory, certificate, calibrated on / due, thermal calibration observations `obs[{std, mv, uuc, unc}]` (Sr. No., standard temperature °C, UUC mV, UUC °C, error = UUC − standard calculated by `obsOf`, uncertainty ± °C) with the confidence level `cl` (%) and coverage factor `k`; `calRecIssues` (completeness: make / model, range, least count, observations, uncertainty / CL / k, an observation outside the range, an observed error above the largest error entered); `eqIssues` uses the largest observed error when no largest error is entered; `satEval` notes a set point outside the calibrated range; "Print record" = MWSPL-F-TC-04, "Calibration CSV" (one row per observation) |
| SAT corrections from the calibration `corrAt`, `satCorrs` | correction = − error of the calibration observations at the temperature the test equipment saw (`satTemp`: mean test reading, else the set point), linear between the observed points either side, the nearest point outside them (noted, no extrapolation); filled into the test instrument / test TC correction when the equipment is chosen (else the register's default correction), offered in the dialog with "Use …" (`corrHint`), a SAT note when the correction entered differs by more than 0.1 °C (`CORR_TOL`), printed with the SAT record |
| Default TC specifications `cfg.tdef` (view `#tspec`) | per chamber: type, use, make, tolerance class, sheath, diameter, length, insertion depth, hot junction (`JUNCTION`), calibration laboratory, calibrated range, range of use (replaces the settings rangeH / rangeT), tube material, tube check interval and tube life (replace the settings tubeCheckDays / tubeReplDays; `fixCfg` moves saved values in); `fromDef` fills a new thermocouple (register, chamber change of a new one, CALOR import, starter), the element's `spec{make, cls, dia, length, depth, junction}`; `specDiff` lists differences (thermocouple dialog, list on the page); the range of use must lie inside the calibrated range |
| Valid SAT `satEval` | instrument and test TC identified and in calibration on the test day; depth rules |
| Insertion depth (P3.1.3.3) `depthIssues` | type K / E test TC: depth required; reused shallower than the deepest earlier use = issue (setting "reuseDeeper"); optional maximum uses |
| SAT trend card `trendCard` | per thermocouple position: valid SATs of every element there, tolerance band, warning lines, pass / warning / fail points (open the SAT), replacements as dashed lines; filters furnace, chamber, warning or failure |
| SAT readings `rd` | 30 minutes of furnace / test pairs per SAT (settings `satMin` 30, `satStep` 1 min, `satStab` 5 °C); `satEval` = mean of the per-reading differences, a reading outside the tolerance turns a pass into a warning, a furnace range above `satStab` is noted; paste from Excel, chart of the difference against ±tolerance, readings printed with the record and in the readings CSV; a record saved before (one reading) is kept and noted as single |
| SAT record (P3.3.5) `satMissing` | thermocouple, date, time, technician, set point, instrument, test TC, the 30-minute series of readings, both corrections, depth (K / E), approval by and date |
| Failed SAT | cause, action, product impact, owner, date; re-SAT shown on the Reactions view |
| Replacements `repl` (`TR-nnnn`) | oldTc / newTc, date, time, removed and fitted serial, type, certificate, reason (`REASONS`, the CALOR cases), controller offset reset (`OFFSET`), TUS decision for a relocation / immersion change (`TUSDEC`), the failed SAT that found it (`satRef`), by, notes; `replMissing`; `verifySat` = first valid SAT of the fitted element on or after the date; until then `satState` = `repl` ("SAT due after replacement"); a failed SAT with action "Replace the thermocouple" closes only with a linked record; view Thermocouple replacements (due list by `lifeDays`, history incl. removed elements recorded before the register, Replacements CSV); HTSA 3.3 item "Replaced elements recorded and verified by a SAT before use"; CALOR's replacement history is imported with the SAT register |
| SCADA furnace readings | `scadaPull` → `MWS.scada.pvAt(f, ch, n, times)`: PV-n of a SCADA record loaded this session (SCADA review or "Load the SCADA export of the test day" → `MWS.scada.load`), nearest row within half the logging step, 500–1000 °C; `src{file, at, n}` on the SAT record |
| Protection tubes `tubeState` | not in the PM schedule (no material / interval), never checked, check overdue, replacement interval passed, last check worn / cracked (open until the thermocouple is replaced: element and tube are one assembly, installed and replaced together; `fillTc` sets the tube's installation date to the element's, only checks on or after it count, the replacement dialog takes the tube material `rp-tmat`, reason "Protection tube failure" preselected for a bad tube, the check round no longer offers "Replaced", the PM schedule is marked changed only when the tube material changes); PM schedule approved (rev, approver, date), changes after approval mark it changed, review every 365 days |
| Element life `lifeOf` | 365 days after installation (setting, 0 = off) |
| HTSA 3.3 `assess33` | the five bullets of the question plus element life; score needs immediate action (nothing registered, or a control TC failed / never SAT checked), not satisfactory (any item not met), satisfactory |
| Data | export / import JSON, register and SAT CSV, import from the CALOR SAT register (from the CALOR Drive folder, Google Drive files or this browser, `MWS.calor`; `tsat-pdca`: thermocouples, SATs with their readings, test equipment), starter set-up, clear all |
| API | `MWS.tc.stats()`, `summary()`, `closeModal()` (Overview) |
| Test hook | `window.__TCM` |

**Not in the application:** the calibration certificates themselves (kept in the maintenance file; the register holds their numbers); TUS and controller / recorder calibration (CALOR TUS and Equipment pages).
