## THERMOCOUPLE STORE ISSUE SLIP AND ISSUE REGISTER

| Doc No. | Rev | Kept as |
|---|---|---|
| MWSPL-F-TC-06 | 00 | Application → Store issues ("Print issue slip" in the issue, "Print register", "Issue CSV") |

An element leaves the thermocouple store only through an issue (MWSPL-QP-TC-01 §6.1a). The issue closes when the element is fitted (replacement record or installation at a position) or returned to the store unused.

Rules in the application: only an element in the store, not in quarantine, ready to fit (certificate, calibration date, largest error; range with a specification) and not already issued can be issued; issued by, received by and the work order are required; an element can be installed at a new position only after it is issued; a replacement that takes an element from the store closes its issue, or records the issue with the replacement when it was not issued before; an issue neither fitted nor returned within the set number of days (setting, default 2, site rule) is listed for attention.
