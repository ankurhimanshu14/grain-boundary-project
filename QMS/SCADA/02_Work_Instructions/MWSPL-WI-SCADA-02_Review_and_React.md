## REVIEW AND REACT

| Doc No. | Rev | Issue date | Used by | Prepared | Approved |
|---|---|---|---|---|---|
| MWSPL-WI-SCADA-02 | 00 | — | Qualified reviewer | | |

### 1. Before the review

Have the furnace / operator log and the alarm history of the same period at hand.

### 2. Conditions to answer

| Condition | Typical reaction |
|---|---|
| Incident, product affected | Hold the trays of the window (positions shown), hardness / metallurgy check, disposition; find the cause (burner, thermocouple, set value) |
| Thermocouple below 100 % in tolerance | Check the thermocouple and the zone control; maintenance order |
| Offline / stuck thermocouple, readings out of range | Check wiring and element; SAT after repair (Thermocouples module) |
| Data gap | Find why the SCADA did not log; check the paper chart / operator log for the gap |
| Not back within tolerance after a set value change | Check the burner capacity / tuning |
| Set value without a specification in force | Correct the set value or approve the specification |
| SAT failed / overdue, element past life | Handled in the Thermocouples module: give its record number |

### 3. Record

| Step | Action |
|---|---|
| 3.1 | For each condition choose "Reaction recorded here" (action, owner, product disposition) or "Handled in another record" (its number). |
| 3.2 | Enter the review time and your name (you must be in the list of qualified reviewers). Note the logs and alarms you checked. Save. |
| 3.3 | When the action is done and checked, enter the closing date and the verification; a reaction with product still on hold cannot be closed. |
| 3.4 | A problem seen on two or more days: open an 8D / CAPA and give its number. |
