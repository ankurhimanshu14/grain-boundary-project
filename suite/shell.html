CALOR data

Google Drive folder

CALOR can keep its data as JSON files (one per register) in a Google Drive folder synced to this computer by Google Drive for Desktop. Every change is written to the folder a moment later, and Drive uploads it; other computers linked to the same folder see the changes within about a minute. The data stays in this browser too, so CALOR keeps working when the folder cannot be reached and catches up afterwards. Needs Chrome or Edge.

Everything you enter is saved in this browser on this computer. All pages share it, and so do the separate page files (HT organization, procedures & WIs, data review, production, load build, trap points, specifications, SCADA review, alarms, quench media, hardness, rework, control plan, trend analysis, SAT, TUS, equipment) when they are opened from this computer in the same browser.

To move the data to another computer or browser, or to keep a copy, download a backup and restore it there.

Data per tab

Reset settings puts the tab's settings back to the defaults and keeps its records. Delete data deletes everything that tab has saved (records and settings); the other tabs are not touched.

Clear all data (every tab)

Deletes everything CALOR has saved in this browser: the heat treat organization (positions, job descriptions, people), procedures and work instructions (documents, points of use, availability checks, employees, training records), second-level reviews of the furnace data and the reviewers, production reports, loading standards, load checks, trays and fixtures, trap points and lot changeover checks, process specifications, SAT register and cycles, temperature uniformity surveys, equipment qualification records, control plans and PFMEAs, thermocouple replacements, quench media tests, hardness and metallurgical tests, the rework procedure and rework log, trend analysis plans and reviews, SCADA reviews and reaction plans, SCADA history, links and settings. The separate page files (HT organization, production, load build, specifications, SCADA review, alarms, quench media, hardness, rework, control plan, trend analysis, SAT, TUS, equipment) opened in this browser use the same data, so they are cleared too. Download a backup first if you may need any of it.

Google Drive folder

CALOR saves its data in the folder . The browser needs your permission again to read and write it.

Without it, CALOR opens with the data in this browser; your changes wait here and are written to the folder once access is given (Data → Google Drive folder → Sync now).
